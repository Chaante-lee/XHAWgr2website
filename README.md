# Empowering The Nation

## Project Overview

Empowering The Nation is a community-focused educational platform designed to provide users with easy access to skills development and training programmes. The website enables users to explore available courses, view detailed course information, generate quotations, and submit enquiries through an interactive and user-friendly interface.

The primary goal of the platform is to promote education, skills development, and community empowerment by making training opportunities more accessible through digital technology.

---

## Project Objectives

The objectives of this project were to:

* Create a professional educational website.
* Provide information about available training programmes.
* Allow users to browse courses by category.
* Enable users to request and generate quotations.
* Support multilingual accessibility for diverse South African communities.
* Improve user engagement through interactive features and intuitive navigation.

---

## Features

### Home Page

* Professional landing page design.
* Clear navigation structure.
* Call-to-action buttons for course exploration and quotation generation.
* Community-focused content and branding.

### Training Programmes

* Categorised course listings:

  * 6-Month Programmes
  * 6-Week Programmes
* Course-specific cards displaying:

  * Course name
  * Description
  * Duration
  * Pricing
  * View Course functionality

### Course Detail Pages

Dedicated pages were created for:

* First Aid
* Sewing
* Landscaping
* Life Skills
* Child Minding
* Cooking
* Garden Maintenance

Each course page contains:

* Course image
* Detailed description
* Learning outcomes
* Pricing information
* Discount information
* Contact and quotation options

### Dynamic Quote Generator

Users can:

* Select multiple courses.
* View calculated totals.
* Receive automatic bulk discounts.
* Generate quotations dynamically.

Discount Rules:

* 2 Courses = 5% Discount
* 3 Courses = 10% Discount
* 4 or More Courses = 15% Discount

### Download Quote Functionality

Users can download generated quotations directly from the browser.

This functionality was implemented using the JavaScript Blob API, allowing files to be generated without requiring server-side processing.

### Contact Page

The contact page includes:

* Name field
* Email field
* Phone number field
* Course interest dropdown
* Message field

### Form Validation

Client-side validation was implemented to:

* Ensure required fields are completed.
* Validate email formatting.
* Improve data accuracy.
* Provide immediate feedback to users.

### Multilingual Accessibility

The platform supports multiple South African languages:

* English
* Afrikaans
* isiZulu
* Sesotho

This feature improves accessibility and promotes digital inclusivity within diverse communities.
